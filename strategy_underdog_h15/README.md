# 弱队受让1.5球策略回测

## 策略逻辑

每场比赛比较两队 FIFA 排名（数字越大 = 排名越低 = 越弱），买入"排名更低的队（弱队）受让 1.5 球后获胜"：

- **弱队是主队**（home_rank > away_rank）→ 买"客让1.5"盘的 no（客队让1.5不成立 = 主队 +1.5 后胜）
- **弱队是客队**（away_rank > home_rank）→ 买"主让1.5"盘的 no（主队让1.5不成立 = 客队 +1.5 后胜）
- **命中条件**：对应让球盘 `settled_yes = 0`（让球不成立 = 弱队受让后胜）

直觉：弱队只要不被强队赢 2 球以上就命中。市场可能高估了强队大胜的概率。

## 结算模型

与 `backtest/backtest.py` 一致：
- 每场固定投入 STAKE（默认 100）买 no_token
- 价格 p = no_price（锚点前 VWAP），赔率 odds = 1/p
- 命中：净收益 = STAKE × (1/p - 1)
- 未中：净收益 = -STAKE

## 数据来源（只读）

- `../wc_odds_factors.csv` — FIFA 排名、阶段、轮次
- `../wc_handicap_odds.csv` — 让球盘 yes/no 价格与结算

## 样本筛选

- 排名不同（相同的跳过）
- no_price 有值、已结算
- no_quality 为 high/medium/fair（默认排除 low/missing，与 1X2 回测一致）

## 用法

```bash
python3 backtest.py                         # 默认 stake=100
python3 backtest.py --stake 60
python3 backtest.py --allow-low-quality     # 纳入低流动性报价
```

## 回测结果

### 整体

| 指标 | 数值 |
|---|---|
| 下注场次 | 103 |
| 命中 | 62（60.19%） |
| 总投入 | 10,300 |
| 净收益 | -530.6 |
| ROI | -5.15% |
| 最大回撤 | 1,526.97 |

### 分阶段

| 阶段 | 场次 | 命中率 | 净收益 | ROI |
|---|---|---|---|---|
| 小组赛 | 71 | 54.9% | -850 | -12.0% |
| 淘汰赛 | 32 | 71.9% | +319 | **+10.0%** |

### 按排名差距

| 差距 | 场次 | 命中率 | 净收益 | ROI |
|---|---|---|---|---|
| 0-10 | 30 | 70.0% | -331 | -11.0% |
| 11-30 | 33 | 60.6% | -437 | -13.2% |
| 31-60 | 30 | 53.3% | -93 | -3.1% |
| 60+ | 10 | 50.0% | +330 | **+33.0%** |

### 分析

整体略亏（-5.15%），但有结构性分化：

1. **淘汰赛盈利**（+10%）：淘汰赛命中率 71.9% 远高于小组赛 54.9%。淘汰赛弱队更倾向死守（新赛制下 3 分可能出线），强队大胜更难。
2. **大排名差距盈利**（+33%）：差距 60+ 时虽然命中率只有 50%，但 no 价格低（赔率高），命中收益大。极端强弱对阵时，市场对强队大胜的定价偏高。
3. **小组赛亏损**（-12%）：小组赛场次多、命中率不够高（54.9%），no 价格偏高（赔率低），命中收益覆盖不了未中亏损。
4. **盈亏平衡**：平均 no_price ≈ 0.6-0.7，盈亏平衡命中率 ≈ 60-70%。整体命中率 60.19% 刚好在平衡线附近，所以略亏。
