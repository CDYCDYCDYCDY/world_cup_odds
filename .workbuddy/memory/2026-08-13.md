## 让球胜负（Spread）赔率拉取
- 用户要求拉取各场比赛开赛前1小时的让球胜负赔率（主让1.5/2.5、受让1.5/2.5），取价方式与1X2对齐，落盘单独表格。
- **市场结构调研**：让球盘不在 1X2 event 下，而在每场比赛的 "More Markets" event 里（title = "{比赛名} - More Markets"）。每场 4 个 spread markets：
  - 主让1.5: slug 含 `-spread-home-1pt5`, outcomes=[主队,客队]
  - 客让1.5(主受让1.5): `-spread-away-1pt5`
  - 主让2.5: `-spread-home-2pt5`
  - 客让2.5(主受让2.5): `-spread-away-2pt5`
- **关键差异**：让球盘 outcomes=[队伍名,对手名]（非 Yes/No），clobTokenIds[0]=让球成立方(yes)、[1]=未成立方(no)。取价需同时对两个 token 算 VWAP。
