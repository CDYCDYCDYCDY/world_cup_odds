# 世界杯 1X2 策略回测

使用 `../wc_odds.csv` 中的赛前市场成交数据与常规时间赛果，回测基础 1X2 策略的理论表现。

> 回测仅用于数据实验。历史结果、单届样本与理论收益不构成实际投注建议。

## 一、数据口径

- **价格锚点**：开赛前 1 小时。
- **正式价格窗口**：锚点之前 3 分钟，即 `[开赛前 1 小时 - 3 分钟, 开赛前 1 小时]`。
- **价格计算**：每个方向的 Yes token 已成交单按成交量加权平均价（VWAP）聚合；十进制赔率为 `1 / VWAP`。
- **赛果**：`result_regular ∈ {home, draw, away}`，对应 90 分钟 + 补时的结果，不含加时赛和点球。

该价格口径严格不使用锚点后的成交，避免前视偏差。

## 二、可回测样本规则

默认一场比赛必须同时满足：

1. 主胜 / 平局 / 客胜三路赔率齐全；
2. 三路报价质量均为 `high` 或 `medium`；
3. 三路市场均已链上结算（`settled == "Y"`）；
4. 存在常规时间赛果（`result_regular`）。

`low`、`partial`、`missing` 代表低流动性兜底、可能截断或无可用成交，默认不进入回测。若需研究其影响，可使用 `--allow-low-quality` 显式纳入。

## 三、结算模型

每场按固定金额 `STAKE` 下注某一路：

- 命中：回收 = `STAKE × odds`；净收益 = `STAKE × (odds − 1)`
- 未中：回收 = `0`；净收益 = `−STAKE`
- ROI = 总净收益 / 总投入

这里的赔率来自历史成交 VWAP，而不是下单瞬间可直接成交的盘口价格。因此结果**不计手续费、买卖价差、盘口深度、滑点或资金限制**。

## 四、当前基准策略

| 策略 | 规则 |
|---|---|
| S1 | 永远买平局 |
| S2 | 永远买主胜 |
| S3 | 永远买客胜 |
| S4 | 主胜 / 平局 / 客胜各买 1/3 |
| S5 | 仅在平局赔率达到阈值时买平 |
| S6 | 买赔率最低的一路，即市场热门 |
| S7 | 买赔率最高的一路，即市场冷门 |

## 五、最近一次回测（2026-07-20）

本次重建后的数据包含全届 104 场已结算比赛；默认质量筛选后，102 场进入回测。决赛常规时间为平局，已按 1X2 市场结算口径计入。

| 策略 | 下注场 | 净收益 | ROI |
|---|---:|---:|---:|
| S1 永远买平局 | 102 | +3956.29 | +38.79% |

这些结果只反映单届、单一锚点与当前阈值下的样本内表现；尤其是 S5 的阈值来自探索性规则，不能视作稳健或可交易的结论。

## 六、运行

```bash
python3 backtest.py                         # 默认每场 100，S5 阈值 5.0
python3 backtest.py --stake 60              # 改每场下注额
python3 backtest.py --value-threshold 4     # 改 S5 平局阈值
python3 backtest.py --allow-low-quality     # 纳入低流动性兜底报价
```

运行后会覆盖生成：

```text
backtest_summary.csv  # 各策略汇总
backtest_detail.csv   # 每场、每策略的逐笔下注明细
```

## 七、结果解读边界

1. 单届世界杯样本很小，正 ROI 可能来自偶然性。
2. 策略阈值若基于同一批历史样本挑选，会产生过拟合风险。
3. 三路概率归一化只使概率和为 1，不能还原实际交易成本。
4. 若要评估策略稳健性，应进一步进行分阶段检验、滚动样本检验和阈值敏感性分析。
